## 五、1.1.9 修复内容

1. **进度页回归**：`_write_progress_page` 引用了不存在的 `file_block`，
   实际应使用已计算的 `bars`。异常从进度回调冒泡后会中断翻译。
2. **进度隔离**：进度回调写入页面失败时不再影响翻译主流程。
3. **Hermes 端点覆盖**：包内默认 `base_url` 改回 8080，服务端才会用 Hermes
   `config.yaml` 的实际端点和 `.api_key` 覆盖默认值。
4. **版本统一**：`plugin.json`、`server.py`、技能、根 `VERSION` 均为 1.1.9。
5. **测试迁移**：冒烟测试改为启动 `hermes-plugin/server.py`，新增版本、
   模型选择弹窗和进度页断言。
6. **打包兼容**：显式 UTF-8 读取 JSON，兼容 Windows PowerShell 5.1。
