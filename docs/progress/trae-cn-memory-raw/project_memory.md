- 翻译插件当前最优技术栈为 llama.cpp 主线（llama-server），需保持可更新以获取 MoE 缓存、投机解码等新特性支持
- 投机解码要求草稿模型与目标模型同词表，Hy-MT2 全家族（1.8B/7B/30B-A3B）共享同一分词器，天然满足投机条件
- 30B-A3B 档在 6GB 显存机器上吞吐漂移大（2.9–10.3 tok/s），不适合作为主力翻译档位，仅可用于抽样质量对照
- 2Bit/1.25-bit 草稿模型依赖 llama.cpp 未合并的 Q2_0c 内核（PR #19357），且当前 x86 CUDA 环境无对应反量化内核，暂不支持使用
- 插件内置模型档位实测结论：1.8B Q8 为日常整 MOD 最优选择（速度最快），7B Q4 适合对话/任务正文等语感敏感场景（质量明显更优），两者开启强制术语后术语准确率均为 100%
- 术语库分层规则：高频无歧义地名格变、固定设施、通用UI词条应从软提示层提升至硬层，人物名、整句对话、通用形容词格变、UI短标签不适合强制硬替换
- 系统物理内存不足时会触发 Windows WDDM 显存压缩/换页，导致翻译速度下降，评测前需确保内存充足避免干扰结果
- 翻译管线核心（X-Ray解析、判定链、术语库、闸门、审计工具链）为纯Python标准库实现，无宿主依赖，具备跨平台可移植性
- 模型接入点已抽象为OpenAI兼容/v1/chat/completions接口，可同时适配本地llama-server与任意平台模型端点
- 术语库源自社区人工汉化包，分发前需完成许可合规审查，避免知识产权风险
- 闸门逻辑需按后端类型分档：在线强模型下自动降级非必要校验，占位符/数字/型号保真校验需对所有模型保留
- v2.0.27版本已完成术语库新一轮深度审计优化，采用全新交叉维度审计工具替代原有审计脚本，完成同源跨类冲突、半角标点等问题的全量修复，全量测试与一致性验证通过，已同步至1.9.x姊妹仓库与桌面部署副本
- 位于硬层的短句模板（≤60字符、带句末标点、属于物品/界面类）不应被审计规则判定为分类错误，需对该类条目设置审计豁免
- 硬层条目不应随意移动至软层，否则会丢失确定性强制替换能力，导致固定提示类译文出现漂移
- 术语库审计需覆盖同源跨类冲突、同译多源、词干族、译文卫生、未译残留五个交叉维度，修复操作需保证幂等性，避免重复修改引入新问题
- MCP 实现无需内置模型与基座，由 Hermes Agent 负责本地模型部署，用户通过独立教程完成模型安装
- 未知模型上下文长度采用保守默认值8192作为安全兜底，不依赖自动探测，用户可根据实际模型能力手动在config.json中调整ctx_size参数
- 2.x版本翻译插件默认模型存储路径为用户本地AppData目录下的STALKER Localization Toolkit/ai_translate/models，仅当插件目录存在portable.txt且assets目录可写时才使用插件自带的assets/models目录
- 多个插件部署副本会共用同一套模型、配置和用户词库，2.x发行包本身不内置模型文件
- Hermes MCP技能不使用插件自带的GGUF模型目录，仅请求独立的Hermes本地模型端点
- Hermes的tool_search机制会将MCP工具默认放入延迟工具列表，低能力指令模型无法主动搜索到MCP工具，需关闭tool_search功能才能让MCP工具直接进入模型工具列表
- MCP翻译任务的模型切换由Hermes路由器负责：Agent使用独立的指令/工具调用模型（如MiniCPM5-2B）理解指令并调用MCP工具，MCP请求时指定翻译模型（如Hy-MT2-1.8B），Hermes自动完成模型换载
- 单模型驻留的6GB显存环境下，翻译期间Agent模型会被换出显存，若Hermes后台任务请求Agent模型会导致翻译模型被挤掉，引发翻译失败或变慢，长任务建议为翻译模型配置独立固定端口的端点避免冲突
- Hermes的MiniCPM5-2B等低能力指令模型在执行MCP安装命令时易产生路径解析错误、幻觉式命令执行，禁止让模型自动执行安装脚本，应提供确定性的双击安装脚本或明确的绝对路径命令避免模型干预
- MCP翻译任务需提供独立的实时进度查看界面，支持显示当前翻译文件、原文与译文内容，同时提供暂停、继续、停止控制与断点续译能力，避免仅依赖Hermes工具行的有限进度展示
- MCP分享包需包含完整术语库、翻译筛选规则、X-Ray解析器与自动安装脚本，不包含用户自定义词库、模型文件与运行日志，确保跨设备分发的兼容性与安全性
- 不再开发独立CLI版本，MCP分享包仅面向Hermes等可部署本地模型的平台，包内内置便携Python，用户无需预先安装Python环境
- MCP分享包内不得包含给模型查看的安装命令，手动安装说明仅放在对外教程中作为兜底功能
- Hermes新安装后默认启用tool_search功能，会导致MCP翻译工具无法被低能力Agent模型发现，需手动关闭tool_search才能正常触发拖入MOD的翻译流程
